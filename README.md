# 🎪 Inforró Web

Bem-vindo ao **Inforró** — o cardápio digital da barraca do **4º ano de Informática do IFRN Campus Apodi** para o Arraiá Geek!

Este projeto reúne em um só lugar:

- 🍔 **Cardápio de comidas e bebidas** — lanches, doces, bebidas e o almoço especial do evento
- 🎮 **LAN House** — catálogo de jogos disponíveis na barraca, com preços e horários

## Projetos

| Pasta | Descrição |
|-------|-----------|
| `Inforró/` | Aplicação React + Vite com cardápio digital interativo |
| `Inforró/cardapio/` | Versão standalone do cardápio (HTML/CSS/JS) |
| `lanhouse/` | Catálogo de jogos da LAN House (HTML/CSS/JS) |

## Como usar

### Cardápio
Abra `Inforró/cardapio/cardapio.html` no navegador.

### LAN House
Abra `lanhouse/lanhouse.html` ou `lanhouse/index.html` no navegador.

### Aplicação React
```bash
cd Inforró
npm install
npm run dev
```
